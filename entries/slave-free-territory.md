# "SLAVE-FREE TERRITORY"
`INTACT`

A short declaration you file with the Guard saying there is no slavery in your jurisdiction. It is granted the moment it arrives. Nobody inspects anything.

**And it is true.** Slavery is defined in the code as holding a person as property, and in the jurisdictions that file this, nobody is held as property.

**What the definition does not cover.** Indenture, where you are not property, you just owe. Custodial labour, where you owe a sentence. Levy, where you owe an instrument. None of those is slavery as written, and each is separately legal.

Sixty-one jurisdictions have filed the declaration. Forty-four of them record lawful indenture in their own returns for the same year.

The standard wording was drafted on Maldo, and it reads exactly like every other Royal ministerial instrument of that period: accurate, elegant, and answering a question nobody asked.
